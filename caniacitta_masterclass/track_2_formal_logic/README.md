# Track 2: Logika Formal & Silogisme Penalaran

## Deskripsi Track
Track ini membekali pembelajar dengan instrumen bedah penalaran formal: membedakan validitas bentuk (*validity*) dari kebenaran isi (*soundness*), menguasai kalkulus proposisional (Modus Ponens, Modus Tollens, Implikasi, Biimplikasi), membedah kuantor logika predikat (∀ vs ∃), menguasai hukum transformasi ekuivalensi (Konversi, Obversi, Kontraposisi, De Morgan), dan memahami batas induksi statistik. Ini adalah fondasi struktural agar argumen Anda kedap air dan tidak runtuh oleh kekacauan semantik.
