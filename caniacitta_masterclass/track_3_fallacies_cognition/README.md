# Track 3: Peta Falasi & Bedah Kerancuan Berpikir

## Deskripsi Track
Track ini adalah sistem imun intelektual (*epistemic immune system*) untuk membedah kerancuan berpikir informal (*informal fallacies*) dan bias kognitif sistemik yang paling sering meracuni ruang publik, percakapan profesional, dan dinamika sosial. Anda akan mempelajari taksonomi falasi secara komprehensif: falasi relevansi (Ad Hominem, Tu Quoque, Genetik), falasi distorsi (Strawman, False Dilemma, Slippery Slope), falasi kausalitas (Post Hoc, Korelasi vs Kausasi), falasi bukti cacat (Cherry Picking, Texas Sharpshooter), serta falasi otoritas dan massa (Ad Verecundiam, Ad Populum).
