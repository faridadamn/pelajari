# Track 5: Dialektika, Debat Produktif & Resolusi Konflik

## Deskripsi Track
Debat sering kali diasosiasikan dengan adu urat leher, penghinaan ego, dan kontes panggung untuk menjatuhkan harga diri orang lain. Track ini mendekonstruksi mitos tersebut dan mengembalikan debat ke martabat tertingginya: dialektika Sokratean untuk mencari kebenaran bersama (*collaborative truth-seeking*). Anda akan mempelajari perbedaan fundamental antara dialektika vs eristik (seni menang debat ala Schopenhauer), psikologi neurobiologis di balik *backfire effect* dan *identity-protective cognition*, taktik menjinakkan aktor beritikad buruk (*bad faith actors: Gish Gallop, Sea-Lioning, Motte-and-Bailey*), retorika publik berbasis logos tanpa demagogi, serta protokol resolusi konflik interpersonal berbasis komunikasi asertif.
