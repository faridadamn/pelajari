# Track 3: Advanced Modern Figma: Design Tokens, Variables & Logic Engines

> "Ketika variabel dan kondisi logika hadir di dalam kanvas desain, batas antara prototipe visual dan aplikasi perangkat lunak yang berfungsi nyata resmi terhapus."

Track 3 adalah lompatan terbesar dalam rekayasa desain antarmuka modern. Anda tidak lagi sekadar menata bentuk mati, melainkan merekayasa sistem token berstandar W3C DTCG yang dapat diekspor langsung ke kode produksi, serta membangun prototipe fungsional berkondisi logika dinamis (*if/else logic*, ekspresi matematika, validasi formulir) tanpa meninggalkan antarmuka Figma.

### Tujuan Pembelajaran Kompetensi

1. **Penguasaan Arsitektur Token Variabel:** Membangun hirarki koleksi variabel Figma (Primitif vs Semantik) yang memisahkan nilai heksadesimal dan ukuran piksel menjadi token dinamis berstandar industri.
2. **Multi-Brand & Multi-Theme Switching Otomatis:** Mengonfigurasi *Variable Modes* sehingga seluruh antarmuka aplikasi dapat berganti tema (*Dark Mode*, *Light Mode*) atau berganti brand anak perusahaan hanya dengan mengubah satu dropdown mode pada Frame induk.
3. **Prototipe Cerdas Tanpa Kode (*Turing-Complete Light*):** Membangun prototipe checkout e-commerce yang menghitung subtotal belanja secara dinamis saat item ditambah/dikurangi, memvalidasi input formulir secara kondisional, dan menampilkan pesan kesalahan realistis.
